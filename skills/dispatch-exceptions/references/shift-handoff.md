# Shift handoff

1. Confirm the company, time window and timezone. Use the user's stated or documented dispatch scope. If several shifts could match, ask for the shift or cutoff time.
2. Retrieve the load queue with the narrowest available dispatch filters. For each possible exception, confirm the relevant stop and latest usable event or ETA. For a requested paperwork check, use `document-readiness` on those same loads if the skill and suitable metadata are available. Otherwise report which paperwork status could not be checked.
3. Start the handoff with the checked window. List confirmed exceptions first, then items needing a check. For each item, give the load reference, the relevant appointment or event, when the evidence was last updated, and the next check that would move the load forward.
4. State any gaps in coverage. Partial results support a brief about the loads actually checked. Present total counts or an all-clear only after a complete check of the requested scope.

Keep the brief ready for the operator to review. Stop after drafting it.
